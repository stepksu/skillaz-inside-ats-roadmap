# Skillaz Inside ATS — рабочий roadmap

Откройте `index.html` в браузере или запустите `python3 -m http.server 4178`.

Данные: `data.js`. Двенадцать инициатив составлены на основе PRD, README, маршрутов API и документации проекта Skillaz Inside ATS. Ни одна не помечена готовой без приёмки. Октябрь–декабрь — предложенная последовательность, а не подтверждённые сроки. Оценки, владельцы и ёмкость не заданы.

Карточки позволяют менять период, статус, владельца и текст оценки. Изменения хранятся в localStorage текущего браузера; совместной серверной базы нет. Экспорт и импорт JSON переносят рабочую версию между браузерами. В исходниках нет персональных данных кандидатов или секретов ATS.

Проверено в браузере: 12 карточек, поиск, открытие карточки, сохранение и восстановление владельца после обновления, отсутствие горизонтального переполнения на ширине 390px. Синтаксис JavaScript проверен node --check.

## Просмотр и доступ

Интерактивный сайт: https://stepksu.github.io/skillaz-inside-ats-roadmap/

Репозиторий и сайт публичные. Сайт публикуется GitHub Pages из корня ветки `main`; обновления файлов в этой ветке автоматически попадают на сайт после сборки.

Для локального просмотра скачайте репозиторий и откройте `index.html`. Правки в интерфейсе хранятся только в текущем браузере; для изменения общего плана обновите `data.js` и отправьте изменения в GitHub.
